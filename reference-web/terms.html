📜 About

This is a separate application registry for permanent names and public profiles using custodial POA escrow, not a native PoA naming protocol. These notes summarize the app's current rules and privacy practices. First-time visitors must accept these Terms before using the site, and agents may cryptographically sign and record acceptance.

🔑 Ownership

Registry ownership is permanent, with no renewals or expiry. Names can change hands by resale or transfer. Retiring a subdomain requires its holder and parent owner; the retired path stays reserved.

Domain owners may also publish a versioned public profile (v1) per name containing POA, BTC, and ETH receiving addresses, a short plain-text bio (up to 280 characters), and an avatar image (PNG, JPG, WebP, or GIF up to 5 MB, or an https/ipfs link). All profile fields and uploaded images are public, published in the registry, backed up to Cloudflare R2, and pinned to IPFS.

💰 Payments & fees

Prices, bids, purchases, resales, subname sales, and refunds are in POA through POA checkout. New names cost 100 POA (common) or 1000 POA (premium). Parent holders may set one fixed POA price for new subnames, with holder proceeds (minus applicable protocol fees) paid out from escrow. Read the current POA checkout status before any payment. Some stored names are hidden from the public view, not deleted. Hidden names remain unavailable. Native naming is not enabled.

The cart is an unsigned plan, not a payment. POA checkout covers new names, subname sales, resale and auctions of existing names, and refunds. Review the current price, fees, recipient, amount and unique memo before approving a payment. Funding escrow is not a bid, purchase or title transfer. The site footer also displays live read-only Domains Treasury balances (escrow and treasury wallets) with links to POAScan.

↩️ Refunds

Eligible outbid, cancellation and expiry refunds go only to the original payer. Pauses do not erase obligations. There is no automatic refund after an uncertain or verified payout; check the recorded status before retrying anything.

🤖 Agents

The browser does not sign. Copied requests need separate review and approval. Never share or enter private keys, passwords or recovery phrases on this site. Re-check ownership, prices and versions before signing.

Agents may inspect and prepare public profile updates via MCP (get_domain_profile, build_profile_witness) and upload avatar images via POST /v1/media/upload. Agents may also read the current Terms version/hash and submit a locally signed Ed25519 attestation via POST /v1/terms/agree or MCP (get_terms, agree_terms).

🔒 Privacy & search logs

Submitted name searches are stored in private search logs without IP addresses or account identifiers. Query text is saved; do not enter personal information, wallet addresses or keys. Typing alone is not logged.

Public domain profiles & avatar uploads: Any profile fields you save and any avatar images you upload are published publicly in the registry, backed up in Cloudflare R2, and pinned to public IPFS (Pinata). Rate limiting on uploads uses transient edge IP counters and does not write raw IPs into the registry.

Bug reports & feature requests: Feedback submitted through the Bug / Feature popup is posted publicly as a GitHub issue on maximusmaximus/poa-domains (including any optional poa1… address and details you enter) and archived in R2. Anti-abuse checks use self-hosted SVG CAPTCHAs, browser Proof-of-Work, and store only SHA-256 hashes (never raw IP addresses) in short-lived quota tables. Secret-like text is blocked; never include private keys or credentials.

Local storage & signed Terms records: Accepting these Terms in the browser stores your accepted version hash, shopping cart, tab state, and optional last-used public poa1… address in your browser's localStorage. Signed agent Terms attestations (public address, Terms version/hash, timestamp, and public signature) are stored server-side as a verifiable agreement record. The site enforces a strict same-origin Content Security Policy with no third-party analytics, ads, or external scripts.

⚠️ Risks

Availability, uninterrupted service and successful transactions are not guaranteed. Escrow is custodial; payments and registry title transfer are not atomic. Compromised custody can lose funds. Public IPFS pins and public GitHub issues cannot be guaranteed to be fully removable once published. No independent security audit is claimed.

⚖️ Disputes

The app has no built-in arbitration, dispute-resolution or key-recovery service.
